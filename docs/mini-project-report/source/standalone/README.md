# QRSathi Mini Project Report — package

This folder contains the mini project report for **QRSathi — QR Code, Barcode and Inventory Management System** and the audit evidence behind it. Everything here was generated from the repository's real source code and from tests executed on 25 October 2026; nothing in the application was modified to produce it.

## Regenerating

Requires Node.js 22 and Chrome or Edge.

```bash
cd docs/mini-project-report/report-tools
npm install
npm run diagrams     # writes ../diagrams/*.mmd|*.puml and renders ../diagrams/rendered/*
npm run build        # writes the PDF, DOCX, XLSX and the Markdown documents
```

`report-tools/build-report.json` records the page count, located headings/figures/tables and a check that all chapters and appendices are present in the DOCX. Screenshots are not regenerated by these scripts; they come from the project's browser test (`SHOT_DIR=<folder> npm run test:browser` against a test server).

## Diagram formats

All diagrams are Mermaid (flowcharts, DFDs, sequence, class, ER). Mermaid has no native UML use-case or deployment diagram type, so those are drawn with flowchart shapes; equivalent PlantUML sources (`use-case-diagram.puml`, `deployment-diagram.puml`, `login-sequence.puml`) are included but were **not rendered**, because no Java/PlantUML runtime was available. Long flowcharts are split into parts (a) and (b) for legibility. Diagrams were rendered locally with Mermaid 11.6 in headless Chrome; no online rendering service was used.

## Known limitations of this package

- The DOCX could not be opened in Microsoft Word on the audit machine (Word/LibreOffice not installed). It was validated structurally (sections, tables, images, headings, TOC fields) and its full text was extracted with `mammoth`; page layout in Word may differ slightly from the PDF.
- Screenshots of workspace pages show empty test accounts; admin screenshots show a test administrator without MFA (hence the 2FA banner).
- Google sign-in, SMTP delivery and live Razorpay payments were not tested; performance was not measured.
